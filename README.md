AI_restaurant se concentrează pe monitorizarea activității dintr-un restaurant utilizând tehnologia de detecție a obiectelor bazată pe inteligența artificială. Prin intermediul unui model YOLO (You Only Look Once), aplicația detectează și urmărește mese, clienți și diverse obiecte de pe mese, precum ustensilele și alimentele. Structura proiectului este organizată pe mai multe module, inclusiv un director dedicat pentru detectoare, un altul pentru interfața grafică utilizator (GUI) și un director pentru utilitare care facilitează procesarea imaginilor și gestionarea statusurilor meselor.

Funcționalitatea principală a aplicației include atribuirea unui ID unic fiecărei mese detectate, monitorizarea statusului fiecărei mese (de exemplu, dacă este liberă, ocupată sau rezervată) și salvarea istoricului acestor statusuri într-un fișier Excel pentru analize ulterioare. Interfața grafică permite utilizatorului să vizualizeze în timp real activitatea din restaurant, inclusiv numărul de clienți și statusurile meselor, afișând informațiile într-un format ușor de înțeles.

Un aspect inovator al proiectului este gestionarea timpului, care permite înregistrarea duratei fiecărui status al meselor în formatul hh:mm:ss. Proiectul are scopul de a îmbunătăți eficiența operațională a restaurantelor prin furnizarea de date valoroase și vizualizări în timp real, ajutând astfel la optimizarea serviciilor oferite clienților.
